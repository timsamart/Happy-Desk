# design-system/happy-desk/pages/home.md

> Overrides [MASTER.md](../MASTER.md) for the Home (Threads) surface.

## Purpose

Compassionate resume surface for Alex. Primary job: ≤30s / ≤2 clicks to restored Thread cursor.

## Show

- Active Threads (≤7 pinned)
- Recently touched (capped, e.g. 14 days)
- Needs-you items scoped to those Threads only
- Capture affordance always visible
- Quiet Knowledge Pulse (collapsed)

## Hide by default

- Full Open Loop inventory (“Show all” only)
- Workspace Atlas
- Ghost proposals
- Global Frontier dump

## Copy

Neutral, specific, reversible: “3 Threads waiting”, “Agent left 2 claims to review”. Never shame counts of neglect.

## Primary action

Row click / Enter → **Resume Thread**. Secondary: Act, Park.
